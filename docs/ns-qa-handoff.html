智能DNS（NS 模式）提测文档

测试环境：admin（贵州）+ api（新加坡 aws-sg-web-obs-05）+ dns-edge（贵州，同 admin 机器）· 更新日期：2026-07-07

背景：dns-edge 是 GoEdge 的自建边缘 DNS 节点，支持两种独立模式：CDN 模式（edgeapi 主动推送 CDN 域名解析记录，用于给已有的 CDN 服务加速）和 NS 模式 / EdgeAdmin 里叫"智能DNS"（自己管理任意域名的权威解析，类似自建一个 DNSPod）。本次提测覆盖"智能DNS"模块整体功能，以及 2026-07-07 当天新增/修复的部分。

0. 环境信息

EdgeAdmin http://111.123.254.177:7788 测试账号找 ivloli 拿
admin 机器 贵州 edge-admin + dns-edge 都在这台机器上
api 机器 aws-sg-web-obs-05（新加坡） edge-api，真正的业务数据库 go-edge-test 也连这台
dns-edge 端口 :5300 DNS 查询端口（UDP+TCP），测试用端口，不是标准 53
注意：这是共享测试环境，同事在这台机器上也有 WAF/CC 防护相关的真实配置数据（策略/规则组），测试智能DNS 功能时不要碰"服务"、"WAF策略"等无关模块的数据。

1. 功能范围

1.1 已有能力（历史开发，本次仅回归）

  • 智能DNS 集群管理：新建/编辑/删除集群，节点管理
  • 域名管理：新建/编辑/删除域名，绑定集群
  • 记录管理：A/AAAA/CNAME/MX/TXT/NS/SRV/CAA 各类型记录的增删改查
  • edgeagent 断线自动重连（dns-edge 主动连 edgeapi 的 gRPC，断线后自动退避重试）
  • 冷启动全量同步（dns-edge 重启后自动拉取全部域名/记录，不需要人工触发）
  • 数据看板（近24小时流量统计、域名/节点排行）

1.2 本次新增 NEW

  • 记录线路（智能解析）：记录可以按"国家/省份/运营商"配置多条不同解析结果，客户端带 EDNS Client Subnet（ECS）查询时按"省份+ISP > 省份 > ISP > 国家 > 默认"优先级降级匹配，跟 CDN 模式已有的地理路由能力一致

1.4 架构调整 CHANGE

摘除了"自动通配符 CNAME"：以前只要给某个 CDN 集群开了 DNS，系统会不经用户同意自动加一条 * 通配符解析——任意子域名（哪怕压根没配置过）都能解析出集群 IP。这个行为经确认是本项目自己加的定制（官方/团队基线分支没有），已经去掉，一共有两处独立实现（后台定时任务 + EdgeAdmin"同步"按钮各一份），都已摘除。现在如果需要泛域名解析，需要在集群的"自动设置的CNAME记录"里手动加一条 *，行为变成用户可见、可控。这个改动只影响 CDN 模式，不影响智能DNS。

测试要点：老环境如果之前已经生成过通配符记录，摘除代码本身不会自动清掉历史数据——需要去对应集群的 DNS 设置页面点一次"同步"，触发一遍清理逻辑，随便编的子域名才会变成查不到（NXDOMAIN）。这次点"同步"之后不应该再重新生成通配符了（这正是之前漏删第二处代码时复现过的问题）；测试时建议清理前后都各 dig 一次做对比确认。

集群管理

智能DNS → 集群管理 → 添加集群（只填名称）→ 保存

保存成功，不再报"服务器出了点小问题"（就是 1.3 里那个 JSON bug）
2

域名管理

智能DNS → 域名管理 → 添加域名 → 集群下拉框选刚才建的集群 → 保存

表单里能看到集群下拉框（之前完全没有这个字段）；保存后域名列表能看到这条记录，不再白屏
3

记录管理 — 增删改查

进入域名详情 → 添加记录（类型 A，随便填个测试 IP）→ 保存 → 记录列表能看到 → 点"修改"改一下值 → 保存 → 点"删除"

添加后记录列表能看到（之前永远是空的）；删除时返回成功，不报 403；dig @<admin机器IP> -p 5300 <记录名>.<域名> A 能查到刚加的值，删除后几秒内（不用重启 dns-edge）就查不到了

3. 记录线路（智能解析）NEW

前置条件：这套测试环境目前 edgeNSRoutes（线路定义表）还没有内置线路种子数据（国家/省份/ISP），需要先联系 ivloli 插入种子数据才能测这一节，否则"线路"下拉框会显示"暂无可用线路"。
1

给记录配置线路

给同一个记录名（比如 test）配置两条不同的 A 记录：

  • 记录1：值 1.1.1.1，线路勾选"省份-上海"+"运营商-电信"
  • 记录2：值 2.2.2.2，线路勾选"省份-广东"+"运营商-移动"
添加/编辑弹窗里能看到"线路"勾选框区域，多选后保存不报错；编辑已有记录时能看到之前勾选的线路被正确回显
2

精确匹配验证

# 上海电信测试IP，应该精确命中记录1
dig @<admin机器IP> -p 5300 test.<域名> A +subnet=122.224.0.1 +short

# 广东移动测试IP，应该精确命中记录2
dig @<admin机器IP> -p 5300 test.<域名> A +subnet=183.232.0.1 +short
第一条稳定返回 1.1.1.1，第二条稳定返回 2.2.2.2（多次执行结果一致，不是随机的）
3

无 ECS / 无匹配时的兜底

# 不带 ECS，两条记录都符合"无地理限制"候选，应该随机
for i in 1 2 3 4 5 6; do dig @<admin机器IP> -p 5300 test.<域名> A +short; done

# 境外IP，两条记录的"国家"都不匹配，同样兜底到全部候选随机
dig @<admin机器IP> -p 5300 test.<域名> A +subnet=8.8.8.0 +short
多次执行能同时看到 1.1.1.1 和 2.2.2.2 两个结果交替出现，不会一直卡死在某一个

3.x 已知限制

  • 只支持内置线路（国家/省份/运营商），不支持自定义 IP 段 / CIDR / 自定义地域线路——这类自定义线路选了也不会生效，属于本次范围之外，后续单独排期
