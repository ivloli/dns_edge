智能DNS 功能需求文档

基于商业版 GoEdge v1.3.9 实地调研  ·  2026-06-30  ·  排除「用户套餐」「套餐设置」两个模块

概览

本文档基于对商业版 GoEdge（http://172.31.32.12:7788）的实地登录调研，完整梳理「智能DNS」模块的所有功能点和数据结构，供开发对齐使用。

架构解耦说明

  • 智能DNS（NS）与 CDN / HTTP 层完全解耦，两套独立数据库表
  • NSDomain（NS域名）≠ Server（网站），互不影响
  • NSCluster（NS集群）≠ NodeCluster（边缘节点集群），独立调度
  • NSRoute（线路）控制 DNS 分地区解析，与 CDN 回源策略无关

3. 记录管理

NSRecordService

记录管理位于域名详情页内，支持 9 种记录类型。

3.1 支持的记录类型

类型说明可自定义
A将域名指向一个 IPv4 地址是
CNAME将域名指向另外一个域名是
AAAA将域名指向一个 IPv6 地址是
MX将域名指向邮件服务器地址是
TXT文本记录，通常用于 SPF 或域名所有权验证（限512字节）是
SRV记录提供特定服务的服务器是
CAACA 证书颁发机构授权校验是
NS将子域名指定其他 DNS 服务器解析否（系统管理）
SOA起始授权机构记录否（系统管理）

3.2 记录操作方法

方法说明
createNSRecord创建单条记录

importNSRecords文件导入记录
updateNSRecord更新单条记录
deleteNSRecord删除单条记录
listNSRecords记录列表（分页）
findNSRecord获取单条记录详情
findNSRecordWithNameAndType按名称+类型精确查询
createNSRecordsWithDomainNames按域名批量创建
updateNSRecordsWithDomainNames按域名批量更新
deleteNSRecordsWithDomainNames按域名批量删除
updateNSRecordsIsOnWithDomainNames按域名批量启停
listNSRecordsAfterVersion增量同步（按版本号）
updateNSRecordIsUp手动标记记录 up / down

3.3 健康检查

层级字段/方法说明

4.3 集群设置（完整子菜单）

① 基础设置 — /ns/clusters/cluster/settings?clusterId=:id

字段说明
name集群名称
timeZone时区（如 Asia/Shanghai）
email管理员邮箱
hostsNS 主机名列表（如 ns1.example.com）
autoRemoteStart是否自动远程启动节点
checkingPorts是否检测端口可用性
detectAgents是否检测 Agent 节点

② UDP — .../settings/udp

默认开启，监听 UDP 53 端口。字段：isOn, listen[]（protocol / host / portRange）

③ TCP — .../settings/tcp

默认开启，监听 TCP 53 端口。字段同 UDP。

④ TLS — .../settings/tls

DNS over TLS，默认关闭。额外字段：sslPolicy（SSL 证书策略）

⑤ DoH — .../settings/doh

DNS over HTTPS，默认关闭，监听 HTTPS 443 端口。额外字段：sslPolicy

⑥ 访问日志 — .../settings/accessLog

字段默认值说明
isOntrue是否开启访问日志
logMissingDomainsfalse是否记录未命中的域名
missingRecordsOnlyfalse是否只记录缺失记录的查询
isPriorfalse是否覆盖全局默认配置

⑦ 应答模式 — .../settings/answer

模式说明
random（随机）有多个查询结果时，随机选取若干结果返回
roundRobin（轮询）有多个查询结果时，按顺序每次返回其中一个；此模式下记录权重不生效

额外字段：maxSize（多记录时最多返回条数）

⑧ SOA — .../settings/soa

字段说明
mName主 NS 服务器名称
rName管理员邮箱（SOA 格式）
serial序列号
refreshSeconds刷新间隔（默认 7200 秒）
retrySeconds重试间隔（默认 3600 秒）
expireSeconds过期时间（默认 1209600 秒 = 14 天）
minimumTTL最小 TTL（默认 3600 秒）
hosts覆盖集群 NS 主机名列表

⑨ 递归DNS — .../settings/recursion

字段默认值说明
isOnfalse是否开启递归解析
hostsnull上游 DNS 地址列表
useLocalHoststrue是否使用本地 hosts 文件
allowDomainsnull允许递归的域名白名单
denyDomainsnull拒绝递归的域名黑名单

⑩ DDoS 防护 — .../settings/ddos-protection

TCP 层 DDoS 防护，默认阈值如下：

字段默认值说明
tcpMaxConnections100000TCP 最大连接数
tcpMaxConnectionsPerIP1000单 IP 最大连接数
tcpMinConnectionsPerIP5触发防护的单 IP 最小连接数
tcpNewConnectionsMinutelyRate500每分钟新连接速率上限
tcpNewConnectionsSecondlyRate300每秒新连接速率上限
tcpNewConnectionsMinMinutelyRate3每分钟新连接最小速率（低于此值不触发）
tcpNewConnectionsMinSecondlyRate3每秒新连接最小速率（低于此值不触发）

10. 解析测试
